# 参考资料

本文件夹包含 Humanizer Skill 的参考资料，来源于 Wikipedia 的 AI 写作研究项目。

## 文件说明

### 1. signs-of-ai-writing.md
**来源:** [Wikipedia: Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)

这是 WikiProject AI Cleanup 项目的主要指导文档，详细列出了 **24 种 AI 写作的典型模式**，包括：
- 内容模式（6种）
- 语言和语法模式（6种）
- 格式模式（6种）
- 交流模式（3种）
- 填充和模糊表达（3种）

每种模式都包含具体的"注意词汇"、问题说明和修改建议。

### 2. wikiproject-ai-cleanup.md
**来源:** [Wikipedia: WikiProject AI Cleanup](https://en.wikipedia.org/wiki/Wikipedia:WikiProject_AI_Cleanup)

这是 Wikipedia 上专门处理 AI 生成内容的维基项目主页，包含：
- 项目介绍和参与方式
- 重要政策和删除标准（G15）
- 相关资源和指南链接
- 研究发现和统计数据
- 相关工具和活动项目

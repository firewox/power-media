# 我的学习 microGPT 过程

> 这篇是我在学习 microGPT 过程中对梯度下降算法的整理。很多人能背出“反向传播”“链式法则”，但真要问一句——为什么“求导”就能让模型变聪明？往往就卡住了。这篇文章从最底层的数学直觉出发，把这件事讲清楚。

## 3. 梯度下降算法学习
microGPT 实现一个“超迷你的 PyTorch 自动求导系统（autograd engine）

1. 核心目标是：让计算机自动帮我们算导数（梯度）
2. “自动算导数”的方法：使用链式法则（Chain Rule）沿着计算图（Computation Graph）反向传播。
3. 可以把它理解成：
  - 前向传播（forward）：先把结果算出来”
  - 后向传播（backward）：“再反过来问：结果变化一点点，每个中间变量应该负责多少？”

这是深度学习训练神经网络的核心。

### 对于梯度下降算法的进一步学习
在这里，为了介绍这个自动求导系统。需要先简单介绍一下什么是反向传播和什么是前向传播，底层的数学原理是什么。其中反向传播也就是梯度下降算法的核心，在神经网络模型训练过程中，需要依靠反向传播更新模型参数，让模型的损失函数 loss 值趋近于最小。梯度下降算法，也就是深度学习中最核心和最基础的概念。

很多人会背：
- “反向传播”
- “链式法则”
- “梯度下降”

但并没有真正理解：为什么“求导”就能让模型变聪明？
我会大概讲一下我理解的，GPT为什么能学习的一些底层数学原理。

#### 1. 先理解：大模型LLM（乃至于泛化到一切神经网络模型）训练到底是在干什么？
假设现在我们训练一个非常小的GPT模型，
- 他看到: ``` I love machine __ ```
- 正确答案是：``` learning ```

但是，模型一开始是随机初始化的。它可能预测为：
```
pizza     20%
banana    15%
learning   1%
```
这种预测效果显然很差。于是我们定义了损失函数Loss
1. 损失函数Loss 可以通俗理解成这个意思：
- “你错得有多离谱？”
- 如果正确答案概率很低：loss 就很大。
- 如果正确答案概率很高：loss 就很小。
- 模型训练的目标其实只有一句话：让 loss 越来越小。

那么问题来了，我们怎么知道参数往哪个方向调整？这个问题其实就可以引申出接下来的简单数学问题，就是导数的意义是什么？

假如，我们有一个函数：
$$ L(w) $$
表示：参数 w 对应的 loss
现在 w=3 ， L=10
如果我们把 w 稍微增加一点，loss 会变大还是变小？
这就是导数： 
$$\frac{dL}{dw}$$

如果 dL/dw > 0 ，则说明 **w 增大会让 loss 变大**。那你应该 **减小 w**。

如果 dL/dw < 0 ，则说明 **w 增大会让 loss 变小**。那你应该 **增大 w**
所以，导数本质上是在告诉我们，**“往哪边走，loss 才会下降”**。

那为什么“负梯度方向”一定会下降？为什么w必须必须要和梯度方向的反方向，也就是“负方向”对着干呢？

我们根据上面的例子也可以直观看出，只要我们和梯度方向反着增大或者减少 w 的值，就能使得 L 逐渐靠拢最小值。

例如：

L(w)=w²

最低点显然在：w=0

现在, w=3 时的导数为，dL/dw = 2w = 6。

这个导数是正数，意思是说，**“当前正在向右上坡”**。所以，我们应该往左走，也就是：**w = w - 学习率 × 导数**。带入数据就是：**w = 3 - 0.1×6 = 2.4**, 我们amazing的发现 loss 下降了。

反过来， 如果 w=-3 ，导数为 -6，说明 **当前向左是上坡**，所以我们应该往右走.代入数据就是：**w = -3 - (-6×0.1)** ,loss同样会下降。

所以 **“负梯度方向”**永远是局部下降最快方向。这是我们刚刚严格发现过的。

#### 2.GPT 是怎么用来训练这个过程的呢
GPT 是：
```text
输入token
→ embedding
→ attention
→ mlp
→ logits
→ softmax
→ loss
```
几十亿次运算。
于是问题变成：loss 怎么对最早的参数求导？

GPT 的前向传播计算过程可能是：
```text
token
 ↓
embedding
 ↓
attention
 ↓
linear
 ↓
softmax
 ↓
loss
```
每一步都有局部导数。反向传播会**从 loss 开始**，一路往回乘。例如：
```text
loss
  ↑
softmax
  ↑
linear
  ↑
attention
```
每层都会说，**“loss 对我的输出有多敏感？”**，然后继续往回传。

##### 举一个真正的 GPT 小例子。
假设：
```text
x = 输入
w = 参数
```
模型：
```text
y = wx
```
loss：
```text
L = (y - target)^2
```
这是最经典的平方误差。

现在：
```text
x=2
w=3
target=10
```
先前向传播：
```text
y = wx = 3×2 = 6
```
计算损失函数值，Loss
```text
L = (6-10)^2
  = 16
```
**现在开始反向传播**。
一步一步链式求导, 我们要求：dL/dw

```text
L 依赖 y
y 依赖 w
```
所以：

$$\frac{dL}{dw} = \frac{dL}{dy} \times \frac{dy}{dw}$$

先算第一部分。

$$ L=(y-10)^2$$

所以：

$$ \frac{dL}{dy}=2(y-10)$$

代入：
```text
y=6
得到 -8
```
再算第二部分：
```text
y=wx
```
所以：
```text
dy/dw = x = 2
```
**所以最终是**：
```text
dL/dw = -8 × 2 = -16
```

这就说明：
> “如果我们增大 w，
> loss 会快速下降”
因为导数是负的。

于是更新：
```text
w = w - 学习率 × 导数
假设学习率：0.1
```
则：
```text
w = 3 - 0.1×(-16)
  = 4.6
```
**现在重新前向传播**：
```text
y = 4.6×2 = 9.2
```
loss：
```text
(9.2-10)^2 = 0.64
```
**从 16 下降到 0.64**
这就是 **学习!!!!**

GPT 本质上也是一样

只不过不是 y=wx。 而是 **几百层 Transformer**， 不是 1 个参数，而是**上万亿参数**, 不是平方误差，而是 **Cross Entropy Loss**, 但本质完全一样的！


1. 前向传播
```text
输入token
→ 得到预测概率
→ 计算loss
```
2. 反向传播
```text
loss
→ 链式法则
→ 每个参数梯度
```
3. 梯度下降
```text
参数 -= 学习率 × 梯度
```

##### 有意思的事情
我们可能很好奇：“为什么仅仅预测下一个 token 就能学会智能？”

这是现代 AI 最令人震惊的地方。

我理解的是，因为模型为了正确预测下一个 token，模型自己被迫学习了：
* 语法
* 逻辑
* 世界知识
* 因果关系
* 人类语言模式
例如：
```text
中国的首都是__
```
为了预测：
```text
北京
```
模型必须内部形成：
```text
中国 ↔ 北京
```
这种知识结构。

于是，“预测下一个 token” 最终逼迫模型内部形成了，世界模型（World Model）
这就是 GPT 最本质的原理吧。

---

**总结一下：**

1. Loss 告诉你错得有多离谱。
2. 导数告诉你往哪边走能少错一点。
3. 链式法则让这个“方向”能从最后一层传回第一层。

GPT 练了上万亿参数，内核就是这三件事重复了无数次。

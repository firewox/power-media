# 截图坐标映射规范

**版本**: 1.0  
**适用范围**: 所有使用 computer-mcp 的 Skills

---

## 问题背景

多模态 AI 模型看到的截图会被**自动压缩/缩放**，而 `pyautogui` 点击使用的是**实际屏幕分辨率**的绝对像素坐标。两者之间存在缩放偏差，导致：

```
原始截图: 2560x1600
模型看到: ~1280x800 (约 2:1 压缩)
偏差结果: 点击位置偏离目标 50%~100%
```

## 核心规则

### 1. 永远使用百分比坐标，不使用绝对像素

```
❌ 错误: 点击 (600, 200)  ← 这是基于压缩图的绝对像素
✅ 正确: 点击百分比 (0.47, 0.25)  ← 水平 47%，垂直 25%
```

### 2. 脚本内自动转换

```python
screen_w, screen_h = pyautogui.size()
real_x = int(screen_w * pct_x)   # 0.47 → 1203
real_y = int(screen_h * pct_y)   # 0.25 → 400
pyautogui.click(real_x, real_y)
```

### 3. 估算百分比的方法

把截图想象成 10x10 网格：
```
(0,0) ──────────────────── (1,0)
  │                          │
  │   (0.5, 0.5) 中心         │
  │                          │
(0,1) ──────────────────── (1,1)
```

### 4. 不确定时用标注验证

```bash
python weibo/lib/mark_coords.py  # 在截图上画出候选坐标
```

## 配套规则

### 中文输入
`pyautogui.typewrite` 不支持中文，必须用剪贴板：
```python
pyperclip.copy("中文内容")
pyautogui.hotkey('ctrl', 'v')
```

### 页面滚动
操作前确保目标元素可见：
```python
pyautogui.hotkey('ctrl', 'home')  # 回到顶部
time.sleep(2)
```

### 窗口聚焦
```python
# 先聚焦到目标窗口，再执行操作
pyautogui.hotkey('alt', 'tab')  # 或其他方式
time.sleep(0.5)
```

## 调试检查清单

遇到点击不准确时，按顺序检查：
- [ ] 坐标是否用了百分比？
- [ ] 截图时页面是否在目标位置？（Ctrl+Home）
- [ ] 窗口是否已聚焦？
- [ ] 中文输入是否用了剪贴板？
- [ ] 运行标注脚本验证坐标位置

## 技术实现方案

### 方案 A: 直接 API 调用
适合有官方开放 API 的平台：
- 微信公众号
- 微博
- 抖音（部分接口）

### 方案 B: 模拟登录 + 请求拦截
适合有网页版管理后台的平台：
- 知乎
- Bilibili

### 方案 C: computer-mcp 浏览器自动化 (截图 + AI 识别)
**核心流程**:
```
截图 (mss) → 多模态 AI 分析截图 → 识别界面元素和坐标 → pyautogui 模拟操作
```

**优势**:
- 不依赖 DOM 选择器，抗页面结构变化
- 多模态 AI 直接理解界面语义，定位更精准
- 更贴近人类操作方式，通用性强

**适用场景**:
- 小红书
- 部分需要复杂交互的平台
- 没有开放 API 的平台

> `inspect_screen` (OCR) 功能保留作为备选方案，但主要识别方式由多模态模型承担。

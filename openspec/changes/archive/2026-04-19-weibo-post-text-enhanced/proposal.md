# Proposal: Weibo Post Text Enhanced

## Problem

当前微博 `post-text` skill 使用固定百分比坐标，存在以下问题：
1. **坐标不灵活**：不同分辨率、不同浏览器窗口大小下坐标偏差大
2. **无智能识别**：无法自动适应微博页面布局变化
3. **无元素检测**：不能自动识别输入框、发送按钮位置

## Solution

实现增强版微博发送功能，引入子智能体进行截图分析和元素检测：

### Key Features

1. **子智能体视觉分析**
   - 使用多模态模型（ollama-cloud/qwen3.5:397b）分析截图
   - 自动识别输入框、发送按钮、头条文章按钮位置
   - 返回四位百分比坐标 [X1,Y1,X2,Y2]

2. **动态坐标计算**
   - 根据识别结果计算元素中心点
   - 支持不同分辨率和窗口大小

3. **截图存档**
   - 所有截图按时间戳命名保存
   - 便于调试和审计

4. **文件输入**
   - 支持从文本文件读取微博内容
   - 便于批量操作和长文本管理

## Success Criteria

- [ ] 子智能体能准确识别微博界面元素（准确率 > 90%）
- [ ] 支持从文件读取内容并发送
- [ ] 截图自动保存到指定目录
- [ ] 3次重试机制，失败时报错退出
- [ ] 与现有 computer-mcp 架构兼容

## Non-Goals

- 不使用 Playwright 进行验证
- 不实现多图文发送（仅纯文本）
- 不自动处理验证码
- 不保存登录状态管理

## Scope

**In Scope:**
- 新脚本 `post_text_enhanced.py`
- 子智能体调用封装
- 截图保存功能
- 文件读取功能
- 四位坐标转中心点逻辑

**Out of Scope:**
- 修改现有 `post_text.py`
- 登录/登出功能
- 图片上传功能
- 自动重发机制

## Risks

| Risk | Mitigation |
|------|------------|
| 子智能体调用失败 | 3次重试机制 |
| JSON 解析失败 | 异常捕获和错误提示 |
| 坐标偏差 | 四位坐标提供更大容错范围 |
| 子智能体响应慢 | 异步调用或超时设置 |

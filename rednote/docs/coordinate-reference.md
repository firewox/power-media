# 小红书坐标映射参考

## 窗口区域划分

```
浏览器窗口 (100%)
┌─────────────────────────────────────────────┐
│  标签页 + 地址栏 + 工具栏    ≈ 8-10% Y     │  ← 浏览器 chrome
├─────────────────────────────────────────────┤
│                                              │
│  小红书页面内容区域          ≈ 10-100% Y   │  ← 页面内容
│                                              │
│  左侧导航栏                ≈ 0-15% X       │
│  主要内容区                ≈ 15-100% X     │
│                                              │
└─────────────────────────────────────────────┘
```

## 关键元素坐标

### 搜索框
- **位置**: 页面顶部中央
- **百分比坐标**: `(0.5, 0.13)`
- **说明**: Y=0.13 跳过浏览器 chrome，定位到小红书页面内搜索框

### 导航栏 - 发现
- **位置**: 左侧边栏顶部
- **百分比坐标**: `(0.05, 0.20)`

### 导航栏 - 直播
- **百分比坐标**: `(0.05, 0.26)`

### 导航栏 - 发布
- **百分比坐标**: `(0.05, 0.32)`

### 笔记卡片（第一行第一列）
- **百分比坐标**: `(0.25, 0.35)`

## 注意事项

1. **永远不要在 Y<0.10 的位置点击** - 那是浏览器 chrome 区域
2. **使用窗口内容区域坐标转换** - 通过 `get_browser_window_rect()` 获取内容区域
3. **每个平台单独记录坐标** - 微博、知乎、微信公众号的布局都不同

# 获取小红书推荐列表

## 工作流程

1. 访问小红书首页
2. 等待内容加载
3. 提取推荐 Feed
4. 返回笔记列表

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| count | number | 否 | 获取数量，默认 20 |

## 输出结果

```json
{
  "success": true,
  "feeds": [
    {
      "noteId": "笔记ID",
      "title": "笔记标题",
      "author": "作者昵称",
      "cover": "封面图URL"
    }
  ]
}
```

## 使用示例

```
用户：获取小红书推荐内容
结果：返回 20 条推荐笔记

用户：查看小红书首页推荐
结果：返回推荐列表
```

## 注意事项

1. 需要登录状态
2. 推荐内容基于用户兴趣

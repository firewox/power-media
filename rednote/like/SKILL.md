# 点赞/取消点赞小红书笔记

## 工作流程

1. 访问笔记详情页
2. 点击点赞按钮
3. 返回操作结果

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| noteId | string | 是 | 笔记 ID 或 URL |
| unlike | boolean | 否 | 是否取消点赞，默认 false |

## 输出结果

```json
{
  "success": true,
  "liked": true,
  "message": "点赞成功"
}
```

## 使用示例

```
用户：点赞这篇小红书笔记 xxxxxx
结果：点赞成功

用户：取消点赞 xxxxxx
结果：取消点赞成功
```

## 注意事项

1. 需要登录状态
2. 重复点赞会自动取消

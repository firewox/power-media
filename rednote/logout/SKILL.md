# 登出小红书账号

## 工作流程

1. 关闭正在运行的浏览器实例
2. 清除本地保存的 Cookie 文件
3. 清除浏览器数据目录
4. 清除登录状态缓存
5. 返回登出结果

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| dataPath | string | 否 | 数据存储路径，默认 `./data` |

## 输出结果

```json
{
  "success": true,
  "message": "已清除所有登录数据"
}
```

## 配置要求

环境变量：
- `XHS_DATA_PATH`: 数据存储路径（可选，默认 `./data`）

## 使用示例

```
用户：小红书登出
结果：已清除所有登录数据

用户：退出小红书登录
结果：登出成功
```

## 注意事项

1. 登出后需要重新执行 get-qrcode 登录
2. 清除的数据包括 Cookie、浏览器缓存、登录状态
3. 登出操作不可逆，请确认后再执行

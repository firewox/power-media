# 发布小红书图文笔记

## 工作流程

1. 检查登录状态
2. 导航到创作者中心发布页
3. 点击"上传图文"
4. 上传图片（支持多张）
5. 填写标题和正文
6. 添加话题标签
7. 设置可见范围等选项
8. 点击发布

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 笔记标题（最多20字） |
| content | string | 是 | 笔记正文（最多1000字） |
| images | string[] | 是 | 图片路径数组（最多18张） |
| tags | string[] | 否 | 话题标签数组（最多10个） |
| visibility | string | 否 | 可见范围：public/friends/private，默认 public |
| scheduleAt | string | 否 | 定时发布时间（ISO 格式） |
| isOriginal | boolean | 否 | 是否原创，默认 true |

## 输出结果

```json
{
  "success": true,
  "noteId": "笔记ID",
  "message": "笔记发布成功"
}
```

## 配置要求

环境变量：
- `XHS_DATA_PATH`: 数据存储路径（可选，默认 `./data`）

## 使用示例

```
用户：发布一篇小红书，标题"美食分享"，内容"今天做了..."，图片是 ["/path/1.jpg", "/path/2.jpg"]
结果：笔记发布成功，笔记ID: xxx

用户：发小红书图文，标题"旅行记录"，上传这些图片并添加话题 #旅行
结果：笔记发布成功
```

## 注意事项

1. 标题最多 20 个字
2. 正文最多 1000 个字
3. 图片最多 18 张，支持 JPG/PNG 格式
4. 话题标签最多 10 个
5. 每日发布量有限制（约50篇）
6. 发布前需确保已登录

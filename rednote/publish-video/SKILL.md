# 发布小红书视频笔记

## 工作流程

1. 检查登录状态
2. 导航到创作者中心发布页
3. 点击"上传视频"
4. 上传视频文件
5. 上传封面图（可选）
6. 填写标题和正文
7. 添加话题标签
8. 点击发布

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 笔记标题（最多20字） |
| content | string | 是 | 笔记正文（最多1000字） |
| video | string | 是 | 视频文件路径 |
| cover | string | 否 | 封面图片路径（可选） |
| tags | string[] | 否 | 话题标签数组（最多10个） |
| visibility | string | 否 | 可见范围：public/friends/private，默认 public |

## 输出结果

```json
{
  "success": true,
  "noteId": "笔记ID",
  "message": "视频笔记发布成功"
}
```

## 配置要求

环境变量：
- `XHS_DATA_PATH`: 数据存储路径（可选，默认 `./data`）

## 使用示例

```
用户：发布小红书视频，标题"日常vlog"，上传视频 "/path/video.mp4"
结果：视频笔记发布成功

用户：发视频到小红书，标题"美食制作"，视频路径是 "/tmp/cooking.mp4"，封面是 "/tmp/cover.jpg"
结果：视频笔记发布成功
```

## 注意事项

1. 视频格式支持 MP4、MOV
2. 视频大小建议不超过 1GB
3. 视频时长建议 5秒-15分钟
4. 标题最多 20 个字
5. 正文最多 1000 个字
6. 视频上传需要较长时间，请耐心等待

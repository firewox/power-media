# 搜索小红书内容

## 工作流程

1. 访问小红书搜索页面
2. 输入搜索关键词
3. 等待搜索结果加载
4. 提取并返回搜索结果

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | string | 是 | 搜索关键词 |
| sortBy | string | 否 | 排序方式：综合/最新/最多点赞 |
| noteType | string | 否 | 笔记类型：不限/视频/图文 |

## 输出结果

```json
{
  "success": true,
  "keyword": "搜索关键词",
  "feeds": [
    {
      "noteId": "笔记ID",
      "title": "笔记标题",
      "author": "作者昵称",
      "likes": "点赞数",
      "url": "笔记链接"
    }
  ]
}
```

## 使用示例

```
用户：在小红书搜索"美食"
结果：找到 20 条搜索结果

用户：搜索小红书"旅行攻略"，按最新排序
结果：找到最新笔记列表
```

## 注意事项

1. 需要登录状态
2. 搜索结果最多返回 50 条
3. 部分内容可能需要登录才能查看

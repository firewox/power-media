# 退出微博登录

## 工作流程

1. 检查是否存在 Cookie 文件
2. 删除 Cookie 文件
3. 返回退出状态

## 输入参数

无

## 输出结果

```
正在退出微博...
Cookie 已清除
退出成功
```

## 使用示例

**示例 1：**
```
用户：退出微博
结果：Cookie 已清除
      退出成功
```

## 注意事项

1. 仅删除本地保存的 Cookie 文件
2. 不会远程登出微博账号
3. 如需完全登出，请在微博网页手动操作
